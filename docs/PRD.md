# Cn2En 智能中译英学习平台 - PRD

## 一、产品定位

**核心理念**：像刷短视频一样简单高效地学习中译英

**目标**：让用户在"刷"的过程中轻松掌握中译英，实现无痛记忆。

**产品调性**：
- 极简、无压力、即时反馈
- 单手操作、一滑切换
- 游戏化的进度感知（streak、连续正确）
- AI 智能辅助（生成、优化、难度分析）

---

## 二、三模式架构

### 模式总览

| 模式 | 用户行为 | 核心目标 |
|------|---------|---------|
| **学习模式** | 看中文 → AI 讲解 → 理解记忆 | 输入学习 |
| **练习模式** | 看中文 → 手敲英文 → 即时反馈 | 巩固记忆 |
| **刷题模式** | 看中文 → 快速作答 → 对错标记 | 快速回忆 |

### 模式切换

- 底部 Tab 导航：`[学习] [练习] [刷题]`
- 用户可随时切换，无需"确认"
- 上次退出时的模式可记忆（localStorage）

---

## 三、学习模式

### 3.1 AI 英文生成/优化

**场景一：纯中文材料**
- 用户只提供中文
- AI 根据中文场景生成英文
- 用户可选择"采纳"或"重新生成"

**场景二：已有英文材料**
- AI 分析现有英文，给出优化建议
- 用户可选择"采纳优化"或"保留原版"

**AI 输出内容**：
- 英文句子
- 场景说明（可选展示给用户）
- 词汇/语法讲解（简短）

### 3.2 学习进度保存

**记录内容**：
- 某条材料是否已学习
- 学习次数
- 最近学习时间

**数据结构**：
```json
{
  "id": 1,
  "zh_text": "我喜欢学习新的编程语言。",
  "en_standard": "I enjoy learning new programming languages.",
  "learned": true,
  "learn_count": 3,
  "last_learned": "2024-01-15T10:30:00Z",
  "segments": ["I enjoy", "learning new", "programming languages."]
}
```

### 3.3 长句拆分（可选）

**AI 自动拆分**：
- 按逗号、连词、从句等自然停顿点切分
- 保证每个片段语义完整

**示例**：
```
原文：Today, because I had a meeting early in the morning, I woke up at six o'clock.

拆分：
1. Today,
2. because I had a meeting early in the morning,
3. I woke up at six o'clock.
```

**用户可手动调整**切分位置

## 四、练习模式

### 4.1 核心交互流程

```
进入练习
    ↓
显示中文句子
    ↓
用户手敲英文输入
    ↓
回车 → 即时显示对错
    ↓
自动进入下一题
```

### 4.2 提示功能

**触发条件**：用户输入到一半停止，超过 5 秒无操作

**提示方式**：
- 显示下一个可能的单词/词组
- 用 `[未输入 →]` 标记未表达的部分
- 颜色区分：已输入（白）、未输入（灰色）

**示例**：
```
已输入：Today, because I had a
提示：meeting early in the morning,
```

### 4.3 颜色标记

**用户输入 vs 标准答案 对比**：
- 正确部分：绿色高亮
- 错误部分：红色高亮
- 未输入部分：灰色虚线

### 4.4 AI 难度分析（可选功能）

**可关闭的"智能难度适配"开关**

**AI 分析内容**：
- 当前句子词汇难度评级（简单/中等/困难）
- 复杂语法结构标记
- 建议替换的简单词汇（供用户选择）

### 4.5 正确率统计

**计算方式**：
```
正确率 = 正确次数 / 练习总次数 × 100%
```

**展示位置**：顶部小字，不喧宾夺主

**作用**：
- 用户了解自己的进步趋势
- 正确率持续走低时建议回顾学习模式

## 五、刷题模式

### 5.1 核心交互

```
进入刷题
    ↓
显示中文
    ↓
用户快速输入英文
    ↓
回车 → 显示对错（颜色标记）
    ↓
自动进入下一题（无停留）
```

### 5.2 颜色标记

| 状态 | 颜色 | 说明 |
|------|------|------|
| 正确 | 绿色 | 用户答案正确 |
| 错误 | 红色 | 用户答案错误，标出正确内容 |

### 5.3 计时功能

**开关控制**：用户可选择开启/关闭

**展示**：题目旁边显示用时（如 `2.3s`）

**不强制**：不计时也能刷题

### 5.4 错题本

- 用户手动将当前题目加入错题本
- 错题本独立入口
- 错题可重新练习

## 六、用户体验设计

### 6.1 "刷"的体验要素

**操作极简**：
- 单手操作，一滑/一回车切换下一题
- 不需要点击任何按钮（回车=提交+下一题）
- 答完直接滑走，零阻力

**即时反馈**：
- 答对 → 绿色闪过 + streak +1
- 答错 → 红色标记 + 正确答案秒显
- 连续答对 → 大字显示 streak 数（如 `🔥 连续 6 题！`）

**进度可视化**：
```
✓ ✓ ✓ ✗ ✓ ✓ ✓
连续 6 题正确！
今日已练习 42 题
```

**静默处理**：
- AI 分析、句子拆分在后台完成
- 用户无感知加载，不打断节奏

### 6.2 适度游戏化

**streak（连续正确）**：
- 连续正确数醒目展示
- 连续 streak 越高，视觉反馈越强烈

**成就系统（可选）**：
- "连续正确 10 题"
- "今日练习 50 题"
- "累计 1000 题"

**每日目标（可选）**：
- 用户设定每日目标（如 20 题）
- 达成后显示鼓励语

### 6.3 界面原则

- 大字简洁，无装饰干扰
- 深色/浅色模式适配
- 移动端单手友好
- 响应式：320px - 1920px

## 七、数据结构

### 7.1 材料表（db.json）

```json
[
  {
    "id": 1,
    "zh_text": "我喜欢学习新的编程语言。",
    "en_standard": "I enjoy learning new programming languages.",
    "en_optimized": null,
    "learned": true,
    "learn_count": 3,
    "last_learned": "2024-01-15T10:30:00Z",
    "segments": ["I enjoy", "learning new", "programming languages."],
    "difficulty": "medium",
    "error_count": 0
  }
]
```

### 7.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 唯一标识（时间戳） |
| zh_text | string | 是 | 中文句子 |
| en_standard | string | 是 | 用户原始英文（若有） |
| en_optimized | string | 否 | AI 优化后的英文 |
| learned | boolean | 否 | 是否已学习过 |
| learn_count | number | 否 | 学习次数 |
| last_learned | string | 否 | 最后学习时间（ISO） |
| segments | array | 否 | 拆分后的片段 |
| difficulty | string | 否 | 难度等级：easy/medium/hard |
| error_count | number | 否 | 错误次数（用于推荐错题） |

### 7.3 错题本（localStorage 独立存储）

```json
{
  "wrong_questions": [1, 5, 8],
  "added_at": {
    "1": "2024-01-15T10:30:00Z",
    "5": "2024-01-15T11:00:00Z"
  }
}
```

### 7.4 用户设置

```json
{
  "timer_enabled": false,
  "difficulty_analysis": false,
  "daily_goal": 20,
  "last_mode": "practice",
  "theme": "auto"
}
```

## 八、技术方案

### 8.1 技术栈

- **前端**：React 18 + Vite 5 + TailwindCSS
- **AI**：MiniMax API（用于英文生成/优化/难度分析）
- **存储**：localStorage
- **目标**：纯前端，零服务器成本

### 8.2 AI 服务（ai.js）

**接口设计**：
```javascript
// 生成英文
generateEnglish(zhText) → { en_text, scene, explanation }

// 优化英文
optimizeEnglish(zhText, enText) → { en_optimized, suggestions }

// 难度分析
analyzeDifficulty(enText) → { level, complex_parts, suggestions }

// 拆分句子
splitSentence(enText) → { segments }
```

### 8.3 性能目标

- 首屏加载 < 1s
- 练习模式响应 < 50ms
- AI 调用异步进行，不阻塞主流程
